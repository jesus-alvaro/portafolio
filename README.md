# Jesús Alvaro · Fotografía y video

Portafolio web (sitio estático). Instagram: @jesus.alvaro_visuals

## Estructura
- `index.html`: toda la página (HTML, estilos y código).
- `img/`: portada, retrato y logo.
- `fotos/<categoría>/<sesión>/`: fotografías del portafolio (`portada/` = imagen de cada categoría).

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub y sube todo el contenido de esta carpeta (incluido `.nojekyll`).
2. Settings → Pages → Source: `Deploy from a branch` → rama `main`, carpeta `/ (root)` → Save.
3. En 1–2 minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Agregar fotos
Copia las fotos (WebP, ~2000 px) a su carpeta y agrega su ruta en `index.html`.
